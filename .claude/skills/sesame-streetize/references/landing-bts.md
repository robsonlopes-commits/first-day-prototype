## What this template needs that the PDPs did not
- **Sections keep their own layout** (hero, Clinicians' Choice band, accordion with picture, buy box `StandaloneProduct`, sell-out notice, timeline, trust carousel, accordion, comparison table, Judge.me reviews, founder hero). Colors are set per section by CSS scoped to `.ss-page--bts` (timeline MINT, second accordion LILAC; the hero stays white, owner) and the page is white behind the transparent sections (`.ss-page--bts { background:#fff }`, the sell-out notice showed the body color otherwise). Between every pair of colors there is a shared `<Seam from to />` (`sesame/Seam.jsx`, also used by the Multi page).
- **Opt-in hooks added to `StandaloneProduct`** (backward compatible): prop `ex = { slotInfoTop, slotQtyHeader({ qty }), onAddToCart }`, gallery entries `[file, alt, overlay]`, and a gallery file starting with `/` is used as is. Same idea as the `MainProductV2` hooks.
- **Stickers with `Stick`** (ss.jsx) on the hero wheel (`.v1-hero-image-inner`, index 0 desktop, 1 mobile: add BOTH or the phone has no sticker) and on the accordions (`.accordion-block__image-wrapper`).
- **Third party fonts** here: the Clinicians' Choice band (Lora, Open Sans), the sell-out notice (system font) and the comparison title (Gelica). Scoped overrides at the end of `sesame.css`. Run the font QA script: it finds them in seconds.
- New sections reused: `CountSection` (stats 10 essential vitamins, 21 organic superfoods, 6 symptoms targeted, 2 gummies a day, all on the live page), `MeetTheGang`, the Home hero closing with the SS logo (the live page ends on the founder hero; the closing is added after it).

## Capturing a live landing page (how the replica was made)
Open the live URL in the Browser pane, list `[id^=shopify-section-]` with heights (sections of height 0 are not rendered for this product and are not mounted), then dump per section the text, `innerHTML` of the rich text, image file names (`currentSrc` without the query), `object-position` of images, and the Judge.me reviews. Put it under a new key of `LANDING` (same shape as `kde`) and a route with `audience`. New image files download on first request into `public/assets/shop`: a placeholder "Missing asset" in the first screenshot is just the download, reload before judging.
